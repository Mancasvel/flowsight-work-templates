Async team update template

An asynchronous update works when the next person can identify what changed and what needs a response. This format puts coordination before a detailed activity history.

By Manuel Castillejo · Updated 2026-10-11

Download Markdown template

How to use this file

  1. Select the project and responsibilities covered by the update.
  2. Lead with verified changes, linking only authorized evidence.
  3. Give each question an owner and explain when a response matters.
  4. Include work context only if it changes the reader's understanding or decision.

Open the file in an ordinary editor or spreadsheet. It is a manual resource, usable with or without FlowSight. It does not imply automatic agent import or integration.

# Async team update

Date: [date]
Scope: [project or responsibility]

## What changed
- [verified outcome + evidence]

## What needs input
- Question: [specific decision]
- Owner: [person or role]
- Consequence of waiting: [affected work]
- Needed by: [date or condition]

## What I will do next
- [action and dependency]

## Context that matters
- [relevant working condition, with uncertainty stated]

Review names, facts, access and personal information before posting.

Review before sharing

Check outcomes against evidence, preserve uncertainty and remove details the reader does not need. Review connected services separately if they process the document. The worksheet itself is a drafting aid, not a guarantee about privacy or compliance.
