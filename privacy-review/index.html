Work-data privacy review worksheet

Follow the actual information journey for each enabled feature. This worksheet records questions to answer; it is not a compliance certificate or legal advice.

By Manuel Castillejo · Updated 2026-10-11

Download Markdown template

How to use this file

  1. Record the actual version, purpose and features enabled.
  2. Separate local analysis from synchronization, external AI and integrations.
  3. Identify necessary information, recipients, access, retention and deletion using current documentation.
  4. In an organization, involve responsible privacy functions and qualified advice where appropriate before deployment.

Open the file in an ordinary editor or spreadsheet. It is a manual resource, usable with or without FlowSight. It does not imply automatic agent import or integration.

A worked example

Fictional example: a local drafting trial is assessed separately from a later request to process a report with an external AI provider.
