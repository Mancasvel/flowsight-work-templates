Weekly work report template

A report should help a reader understand progress or make a decision. This template separates verified outcomes from activity and gives pending decisions an explicit owner.

By Manuel Castillejo · Updated 2026-10-11

Download Markdown template

How to use this file

  1. Define the audience and the decision before collecting details.
  2. Compare a FlowSight summary with real project evidence; activity alone does not establish completion.
  3. Put unverified or pending work under work in progress.
  4. Describe blockers as specific requests, then inspect the final document and recipient.

Open the file in an ordinary editor or spreadsheet. It is a manual resource, usable with or without FlowSight. It does not imply automatic agent import or integration.

A worked example

Fictional example: installation guide reviewed in environment A; validation in environment B is pending; access is required before choosing a publication date.

Template preview

# Weekly work report

Period: [start – end]
Project: [project]
Audience: [reader]
Decision this update supports: [purpose]

## Verified outcomes
- Outcome: [what changed]
  - Evidence: [authorized reference]
  - State: [reviewed / delivered / accepted]

## Work in progress
- [work and remaining validation]

## Blockers and decisions
- Missing input: [specific question]
- Affected work: [consequence]
- Decision owner: [person or role]
- Needed by: [date or condition]

## Next steps
- [action] — [owner] — [date or condition]

## Final review
- Check facts and period.
- Remove unnecessary personal or client information.
- Check recipient access to references.
- Inspect the final file before sharing.

Review before sharing

Check outcomes against evidence, preserve uncertainty and remove details the reader does not need. Review connected services separately if they process the document. The worksheet itself is a drafting aid, not a guarantee about privacy or compliance.
