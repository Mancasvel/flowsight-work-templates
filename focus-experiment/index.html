Focus experiment worksheet

Try one small adjustment around a real task. This worksheet keeps observations separate from explanations so that a convenient metric does not become a claim about cause.

By Manuel Castillejo · Updated 2026-10-11

Download CSV worksheet

How to use this file

  1. Choose a task with an identifiable outcome and note what the available context misses.
  2. Observe the usual routine before changing anything.
  3. Try one adjustment, retaining a route for urgent needs.
  4. Compare the outcome and experience; record whether to retain, revise or stop the adjustment.

Open the file in an ordinary editor or spreadsheet. It is a manual resource, usable with or without FlowSight. It does not imply automatic agent import or integration.

A worked example

Fictional example: testing lacked a continuous window; regroup one recurring meeting for the trial and compare whether the task can be completed with the needed checks.

Review before sharing

Check outcomes against evidence, preserve uncertainty and remove details the reader does not need. Review connected services separately if they process the document. The worksheet itself is a drafting aid, not a guarantee about privacy or compliance.
